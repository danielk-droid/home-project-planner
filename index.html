HOW / THE SYSTEM

How the planner turns a home project into a usable path.

The system combines official property information, explicit project rules, and adaptive questions. Each layer has a different job.

01

Property context

The planner first resolves the Newton address against official city data. That establishes facts such as the parcel, zoning, mapped wetlands, floodplain, streams, and historic context where available.

02

Adaptive questions

Questions are not a generic intake form. Answers change what appears next. If an answer is uncertain, the planner can ask a clarifying question beneath it instead of forcing a guess.

03

Rules before AI

Explicit rules determine which documented requirements and conditions apply. The AI layer can help explain and organize the result, but it is not allowed to become the source of truth.

04

Evidence and uncertainty

Results are separated into verified, conditional, and confirmation-needed items. Property-specific uncertainty stays visible instead of being presented as a definitive answer.

05

A project record

The generated plan is saved locally in the browser. It keeps the property context, answers, current checklist state, and source-backed planning path together so the homeowner can return later.

06

What it does not do

It does not issue permits, approve construction, replace professional judgment, or guarantee that every requirement has been discovered. The purpose is to make the planning path easier to understand and work through.

PRIVACY

Privacy

No account is required. Project information is currently stored in your browser using local storage. The planner uses the address you enter to query official Newton public GIS data so it can establish property context.

Do not enter sensitive personal information into project notes. This prototype is not a secure document-management system.

TERMS

Use of the planner

Home Project Planner provides informational planning assistance only. It does not constitute permitting, legal, architectural, engineering, construction, or other professional advice.

Requirements can change, public data can be incomplete, and property-specific conditions can affect the result. Confirm applicable requirements with the appropriate Newton department and qualified professionals before beginning work.

THE PROBLEM

One project can cross many departments.

A basement renovation may involve building, fire, electrical, plumbing, energy, and egress questions. An addition can add zoning, setbacks, lot coverage, trees, conservation, historic review, engineering, and inspections.

Home Project Planner brings those pieces together around one property and one defined project. The website uses official property information to establish context, then asks questions that can actually change the planning path.

The resulting plan separates established requirements from conditional items and questions that still need confirmation. Relevant official sources stay attached to the work they support, so homeowners can see where the information came from.

Home Project Planner is not a permitting authority or an approval system, and it does not replace a contractor, architect, engineer, inspector, designer, or other qualified professional. The purpose is narrower: make the complicated first stage of a home project easier to understand and act on.

WHAT THE WEBSITE IS FOR

Less searching. Less guessing. A clearer path through the work.

Home Project Planner starts with the property, follows the proposed work, and connects the relevant local requirements to official sources. Homeowners should not need to know which department owns a rule before they can understand that the rule may matter.

The website also keeps uncertainty visible. Some requirements can be established from official information; others depend on dimensions, existing conditions, historic status, site conditions, or details that still need confirmation.

The long-term goal is a planning record that remains useful while the project moves forward: a homeowner can return to the same project, work through its checklist, revisit the workflow, and keep open questions in view.
