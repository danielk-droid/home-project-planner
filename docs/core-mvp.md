# Core MVP

## Flow

Address -> official GIS -> PropertyContext -> adaptive questions -> deterministic rules -> dependency plan -> evidence UI.

## Deliberate limitations

The prototype does not assert final permit approval, code compliance, historic approval, conservation jurisdiction, or zoning compliance when the underlying facts are incomplete. It surfaces confirmation requirements instead.

## V1 scope

The first four project types are intentionally different enough to exercise interior, trade, exterior/site, and expansion logic without attempting to cover every Newton project.
