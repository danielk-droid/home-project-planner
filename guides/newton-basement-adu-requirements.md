# What building code rules apply to building an ADU in a basement in Newton, MA?

> A basement ADU must qualify as a self-contained dwelling unit with sleeping, cooking, and sanitary facilities and a separate entrance that meets safe-egress requirements. Massachusetts ADU regulations do not replace the state building code or fire-safety rules. The exact ceiling height, emergency escape opening, and fire-separation requirements must be confirmed for the proposed basement design.

## State ADU definition

- Massachusetts defines an ADU as a self-contained housing unit with sleeping, cooking, and sanitary facilities on the same lot as the principal dwelling, with a separate entrance. (Source: [760 CMR 71.00 — Protected Use ADUs](https://www.mass.gov/doc/760-cmr-71-protected-use-accessory-dwelling-units/download))

## Building and life-safety code

- The state ADU regulation states that it is not intended to supersede the Building Code, Fire Code, Lead Law, or other state and federal health and safety laws. (Source: [760 CMR 71.00 — Protected Use ADUs](https://www.mass.gov/doc/760-cmr-71-protected-use-accessory-dwelling-units/download))

## Questions and answers

### Does the ADU law waive basement egress or ceiling-height rules?

No. The ADU regulation does not supersede the state Building Code or Fire Code. The proposed basement unit must meet the applicable building and life-safety requirements. (Source: [760 CMR 71.00 — Protected Use ADUs](https://www.mass.gov/doc/760-cmr-71-protected-use-accessory-dwelling-units/download))

## What to confirm with the City

- Minimum ceiling height for the proposed basement layout
- Required emergency escape and rescue openings
- Separate entrance and safe-egress design
- Fire-resistance, sound separation, smoke alarm, and carbon-monoxide requirements
- Moisture, ventilation, insulation, and combustion-air requirements
- The applicable Newton ADU size and zoning limits
- Contact: [Inspectional Services Department](https://www.newtonma.gov/government/inspectional-services)
