# Do new homes and renovations in Newton have to be all-electric?

> Yes, for projects that trigger the rules. Newton says complete building permit applications received after January 1, 2024 fall under the Specialized Energy Code. Starting January 1, 2025, all new construction and major renovation projects must electrify heating, cooling, cooking and clothes drying.

## What Newton says

- Complete building permit applications received after January 1, 2024 are subject to the Specialized Code. (Source: [Energy Code / Fossil Fuel-Free](https://www.newtonma.gov/government/inspectional-services/energy-code))
- Since January 1, 2025, all new construction and major renovation projects must electrify heating, cooling, cooking and clothes drying, with electricity or thermal solar for hot water. (Source: [Energy Code / Fossil Fuel-Free](https://www.newtonma.gov/government/inspectional-services/energy-code))
- Newton's 2026 notice says projects that trigger the fossil-fuel ordinance must be fully all-electric. (Source: [Energy Code / Fossil Fuel-Free](https://www.newtonma.gov/government/inspectional-services/energy-code))
- Electrical permit applications are filed online. (Source: [Electrical Permits](https://www.newtonma.gov/government/inspectional-services/electrical-permits))

## Questions and answers

### Does Newton require all-electric homes?

For new construction and major renovations, Newton requires electrified heating, cooling, cooking and clothes drying (since January 1, 2025). (Source: [Energy Code / Fossil Fuel-Free](https://www.newtonma.gov/government/inspectional-services/energy-code))

### What energy code applies in Newton?

The Specialized Code applies to complete building permit applications received after January 1, 2024. (Source: [Energy Code / Fossil Fuel-Free](https://www.newtonma.gov/government/inspectional-services/energy-code))

### Do I need a permit to install a heat pump?

Heat pumps involve electrical work, and Newton electrical permits are filed online by a licensed electrician. Confirm any other permits with the City. (Source: [Electrical Permits](https://www.newtonma.gov/government/inspectional-services/electrical-permits))
