# How long is a Newton building permit valid, and how do you request an extension?

> The Massachusetts building-code guidance says a permit may expire if work does not begin within 180 days after issuance. The code also addresses work that is suspended or abandoned after it starts. Confirm the permit's current status and any written extension with Newton's building official before relying on an old permit.

## The 180-day rule

- Massachusetts states that a building permit may expire if work does not commence within 180 days of issuance. (Source: [Massachusetts Tenth Edition State Building Code Announcement](https://www.mass.gov/news/10th-edition-of-the-state-building-code-board-of-building-regulations-and-standards))

## Extensions

- The building code provides for written extensions by the building official under the conditions and time limits stated in the code. (Source: [Massachusetts State Building Code, 780 CMR, Tenth Edition, Section 105.2](https://www.mass.gov/doc/bbrs-10th-edition-building-code/download))

## Questions and answers

### Does a permit stay valid indefinitely after it is issued?

No. Massachusetts guidance identifies a 180-day period for starting work and warns that a permit may expire when work does not commence within that period. (Source: [Massachusetts Tenth Edition State Building Code Announcement](https://www.mass.gov/news/10th-edition-of-the-state-building-code-board-of-building-regulations-and-standards))

## What to confirm with the City

- The permit's issuance date and any recorded start of work
- Whether work has been suspended or abandoned
- Whether the building official granted a written extension
- Whether the permit must be renewed or a new application filed
- Whether fees or approved plans have changed
- Contact: [Inspectional Services Department](https://www.newtonma.gov/government/inspectional-services)
